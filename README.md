# Курсач 3

## Краткое описание
Проект "Курсач 3" представляет собой учебный проект, разработанный в рамках курсовой работы. Основная цель проекта — демонстрация навыков работы с Python и Git. Проект включает в себя простой скрипт `app.py`, который выполняет базовые операции.

## Установка и запуск

### Установка зависимостей
Для установки необходимых зависимостей выполните команду:
```bash
pip install -r requirements.txt
```

### Запуск проекта
Для запуска проекта выполните команду:
```bash
python app.py
```
